# Web / 桌面端设计参考

这些数值是经验参考，不是硬规范。若项目已有 Design System、平台规范或实际内容密度与下列建议冲突，以项目和平台为准。

## 布局与间距
- 阅读型内容常见最大宽度约 720px；仪表盘/编辑器常见约 1200px；沉浸式工具可全宽。
- 可采用 4pt 或 8pt 空间体系，例如 4, 8, 12, 16, 20, 24, 32, 40, 48, 64。
- 建立共享对齐线；不要默认全部居中。
- 桌面侧边栏常见约 220–280px，但应随导航复杂度和窗口宽度调整。

## 字体
Web 优先系统字体栈，不打包 Apple 专有字体：

```css
font-family: -apple-system, BlinkMacSystemFont, "Helvetica Neue", Arial, sans-serif;
```

经验层级：
```text
大展示标题  48–72px
页面标题    32–44px
章节标题    22–28px
卡片标题    17–20px
正文        15–17px
次要文字    13–15px
说明文字    11–13px
```

正文行高常见 1.45–1.65；常用字重 400/500/600，700 少量使用。

## 材质与颜色
- 中性表面 + 少量强调色优先。
- 半透明材质用于导航、工具栏、浮层等短时或分层界面，不用于高密度正文。
- 使用 backdrop-filter 时提供实色回退。
- 圆角应少而统一，例如 8/12/16/24px，而不是每个组件不同。
- 阴影用于表达悬浮层级，不作为装饰。

## 控件
- 常规触控目标约 44×44px；密集桌面界面可适当收紧，但不能牺牲可用性。
- 分段控件适合少量互斥选项；菜单要支持键盘并明确危险操作。
- 标签页用于同一上下文的同级内容；面包屑只用于真实层级。

## 动效
经验时长：
```text
按钮反馈          80–120ms
小状态变化        140–200ms
面板/菜单         200–300ms
大型空间过渡      300–450ms
```

这些时间不是硬标准。优先根据交互距离、输入方式、现有动效系统和 reduced motion 设置调整。
