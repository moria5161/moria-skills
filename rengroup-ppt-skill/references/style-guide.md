# 任组 PPT 样式规范

本文件记录内置模板和现行组内规范。用户提供新版任组模板时，母版、布局、继承颜色和模板资产以新版为准；下列固定数值作为回退参考。若用户明确说明组内字体或其他硬规范也已更新，则同步采用新规范。

## 视觉识别

| 元素 | 内置模板 / 现行规则 |
|---|---|
| 模板 | `assets/RenGroup-PPT-template.pptx` |
| 页面尺寸 | 13.333 × 7.5 英寸（16:9） |
| 标题色 | 深红 `#800000` |
| 结论框 | 红色 `#C00000`、无填充、虚线圆角 |
| 正文色 | 黑色 |
| 背景 | 白底 + 模板彩色分隔线 |
| 中文字体 | 黑体 |
| 英文与数字字体 | Arial |

## 字体与字号

| 角色 | 内置模板参考 | 处理 |
|---|---:|---|
| 封面标题 | 约 32 pt | 居中、加粗，服从模板构图 |
| 内容页标题 | 约 32 pt | 顶部居中、加粗，尽量单行 |
| 主叙述 | 20–24 pt | 左对齐为主，短句 |
| 页面结论 | 20–24 pt | 结论框内黑字 |
| 图例 / 批注 / 引文 | 14–16 pt | 靠近对应证据 |
| 表格文字 | 14–16 pt | 按数据类型对齐 |
| 图内文字 | 14–16 pt | 过小时优先重绘图 |
| 坐标轴 | 至少约 12 pt | 插入后的最终尺寸仍可读 |
| 页码 | 继承模板 | 不与标题冲突 |

混合文本应正确设置东亚字体与拉丁字体映射。不要为了塞内容把正文、表格或坐标轴压到演示距离不可读。

## 标题与页面层级

- 内容页标题使用模板标题区域，保留页码和彩色分隔线。
- 标题尽量单行；先精简标题或换页，再考虑缩小。
- 结果页应让关键图、谱图、流程或紧凑表格承担主要证据，避免大段纯文字。
- 每页只有一个视觉主角，次要解释围绕主证据组织。

## 结论框

结果、对比、讨论和总结页在存在页面级结论时使用。
- 优先位于底部主要内容区，特殊布局可在右下。
- 复制模板资产，避免手工近似重画。
- 结论通常一至两行，解释“证据说明了什么 / 为什么重要”。
- 不使用实心红底、发光、阴影等额外效果。

## 图片与图表

- 优先 SVG、EMF 或可编辑原生图表；位图保持纵横比。
- 位图最终显示尺寸下建议至少 150 ppi；复杂谱图和显微图通常需要更高分辨率。
- 裁去无意义白边，但不要裁掉坐标轴、单位、图例、误差线和来源。
- 同组图表保持线宽、颜色、符号和统计表达一致。
- 原图文字过小时优先重新生成图，而不是单纯放大低分辨率位图。
- 不确定性、误差线、置信区间、显著性或样本量影响解读时必须说明。

## 表格

- 默认不使用彩色单元格填充，包括表头。
- 仅保留阅读结构需要的细线；用字重、间距或分隔线区分层级。
- 同一指标统一小数位和单位；数值列对齐。
- 表格过密时删列、缩短表头或拆页，不靠缩小字号解决。

## 布局与密度

- 页面任务优先于“填满页面”。
- 保留稳定外边距与内容块间距，避免元素贴边。
- 一个主视觉 + 必要解释优先于多个同等权重方框。
- 内容页左下角不新增日期、时间戳或研究周期。
- 具体版式选择见 [template-map.md](template-map.md)。

## 内容检查

- 标题是否准确表达本页任务或发现？
- 关键证据是否无需先读结论框也能被看见？
- 结论是否解释意义而非复述标题？
- 缩写是否首次出现时定义？
- 样本量、误差、验证条件和限制是否在需要时出现？
- 所有占位符、示例引文、示例姓名/日期是否已经清除？
