# 任组模板版式映射

## 使用范围

以下页码仅对应当前内置模板 `assets/RenGroup-PPT-template.pptx`。内置版本包含 10 个示例页，可复制后替换内容。

**如果用户提供新的任组模板，不要继续假设“第 4/6/8 页”等旧映射有效。** 应先渲染新模板、提取文字并按“封面 / 目录 / 导航 / 流程 / 窄图 / 宽图 / 总结”等语义角色重新识别可复用页面。

| 内置源页 | 语义角色 | 适合内容 |
|---:|---|---|
| 1 | 封面 | 汇报题目、汇报人、必要日期 |
| 2 | 完整目录 | 首次展示完整结构 |
| 3、5、7、9 | 章节导航 | 章节切换与当前位置提示 |
| 4 | 三阶段 / 三组对比 | 三条件、三阶段、方法对照、流程 |
| 6 | 窄图 + 解释 | 谱图局部、装置图、单列流程、机制图 |
| 8 | 宽图/表 + 解释 | 主结果、宽表、热图、综合图 |
| 10 | 总结与展望 | 总结、局限、展望 |

## 选择原则

先判断页面任务，再选布局，不按“实验顺序”机械套页：
- 三个对象需要并列比较 → 三组对比；
- 一个窄视觉对象需要解释 → 窄图布局；
- 一个主结果需要最大视觉空间 → 宽图/表布局；
- 章节切换 → 导航页；
- 汇报收束 → 总结页。

可以多次复制同一版式，最终汇报不受模板示例页数限制。只有现有版式无法清楚表达时才新建布局；新布局仍继承母版、标题、页码、分隔线和组内视觉系统。

## 模板资产处理

- 页面复制后必须替换全部示例内容，不只覆盖可见文字。
- 内置模板中的 `汇报题目`、示例汇报人、`2026.xx.xx`、`xxx`、`图1–图4`、`表格`、示例引文、省略号、示例结论与总结文本均属于占位内容。
- 第 4、6、8 页的红色虚线圆角框是可复用结论资产。
- 目录/导航页的浅灰文字属于层级状态，不应误删。
- 标题、页码、分隔线和占位符编辑后都必须通过最终渲染复核。
