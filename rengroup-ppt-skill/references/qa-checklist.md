# 任组 PPT 视觉验收清单

结构审计不能代替视觉检查。最终稿必须以实际渲染页面为准。

## 1. 全局缩略图检查
先查看整套幻灯片的缩略图 / contact sheet：
- 章节节奏是否清楚；
- 页面密度是否忽高忽低；
- 标题、主图和结论框位置是否稳定；
- 是否连续多页都是同一种构图；
- 是否有明显“模板页未清理”或异常空白页。

## 2. 逐页检查
每页至少检查：
- 标题与页码是否完整、无遮挡、无裁切；
- 主证据是否一眼可见，解释是否围绕证据；
- 图片是否拉伸、模糊或裁掉坐标/图例；
- 表格、坐标轴、图例、引文是否在投影距离下可读；
- 元素是否重叠、贴边、间距失衡或意外换行；
- 结论框是否对应本页证据；
- 是否残留示例姓名、日期、xxx、图/表占位符、示例引文或总结文字。

## 3. 科学内容检查
- 数值、单位、样本量、误差和显著性表达是否与源材料一致；
- 基线、方法、指标和方向是否明确；
- 图表来源和引文是否真实且对应；
- 限制是否被视觉设计隐藏；
- 没有证据的推断是否被误写成确定结论。

## 4. 复验
发现问题后修改，并重新：
1. 运行结构审计；
2. 渲染修改后的全部页面；
3. 至少复查修改页及其前后页面；
4. 再看一次全局缩略图。

只有最后一次修改之后仍完成上述检查，才可以称“逐页视觉质检完成”。
